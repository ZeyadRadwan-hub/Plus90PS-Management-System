# Plus90PS Management System

Plus90PS is a scalable management system for PlayStation shops.  
The system is designed to help shop owners and staff manage branches, consoles, gaming sessions, pricing rules, users, roles, and reports.

## Current Repository Content

This repository currently contains the planning and design phase of the project, including:

- Project documentation
- Requirements analysis
- System diagrams
- UI designs
- Release planning
- Future implementation roadmap

## Planned Tech Stack

- ASP.NET Core Web API
- SQL Server
- Entity Framework Core
- WPF Desktop Application
- Future Web/Mobile support using the same backend API

## Main Modules

- Branch Management
- Console Management
- Session Management
- Pricing Management
- User and Role Management
- Reports and Analytics

## Project Goal

The goal of this project is to build a reliable and scalable system that can support PlayStation shops from a single branch to multiple branches in the future.
